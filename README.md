## 关于使用

- 以下内容均为本人自行探索，可能有误，敬请指正。

- CT表使用方法不再赘述，Cheat Engine请自行下载。下面主要讲讲一些注意事项和可能存在的问题。

- 随表还提供了PTR文件，供各位自行修改。

- 建议**不要**在过剧情（剧情CG）时修改数值，可能造成游戏崩溃。最好只在空闲时，即在庭院中可以选择操作的时候进行修改。

## 关于基础数值

- 表中的灵魂值只是右上角的显示的数值，修改这个数值并无实际意义。**显示值和实际值可能存在小范围差值（比如本人的游戏中相差了40）**！关于灵魂的实际值，我在测试不同存档（本人的存档和其他人的存档）时，发现它的基址可能是不一样的，即在不同玩家的游戏中，基址可能不同。但是在个人的不同存档中，其基址似乎是相同的。

- 如果想要修改灵魂的实际值，有两种情况能看到实际值：一是在拍卖会上可以直接看到实际值；二是在游戏后期打开幻境泡时，解锁房间时可以看到实际值。也可能有其他时候可以看到，敬请补充。

- 营业额、建设度、探知度**不建议修改**，这几个数值与游戏体验和发展联系紧密，我不清楚修改可能的后果，如果一定想修改，建议提前存档备份游戏进度。

- 屠杀熟练度**不建议修改**，它的上限为100,000，达到该数值后，再进行屠杀，屠杀等级即变为MAX（99,999,999），此时**修改不再生效**。

## 关于探索

- 山林探索有四个探索方向，探索进度存储的地址疑似会考虑四个方向的探索**先后顺序**。举例而言，如果第一个探索方向为东方平原，那么表中“第一个探索方向”对应的值即为东方平原的探索进度（%）。使用者可以尝试简单修改数值来确定自己的探索顺序实际情况。

- 如果是新游戏或者新档（山林探索功能开启之前），可能呈现“??”，这是**正常现象**。第一次进行山林探索后，表中数值即开始呈现。

- 进入游戏后，刚刚打开CT表时，山林探索有可能呈现“??”，这是**正常现象**，可以点进星野商店再退出，此时数值显示正常。

## 关于角色好感

- 角色好感度与等级的大致范围我已经测出来了，详见表格[角色好感.xlsx](角色好感.xlsx)。建议不要贴着上下限修改。

- 每一次共度时光时，增加的好感度是由好感等级决定的，因此可以把等级改高，这样每次增加好感度更多（慎重使用）。
